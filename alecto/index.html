alecto

GitHub: https://github.com/aquaxis/alecto

Overview

Alecto (Autonomous Logic Executor for Complex Task Operations) is a tool-extendable AI chat CLI application that combines a local Ollama LLM with MCP (Model Context Protocol) servers for tool calling such as file operations and web search.

Features

  • Chat with local LLMs served by Ollama (`ollama serve`)
  • Tool calling through MCP servers — filesystem, web search (DuckDuckGo MCP server), or any MCP-compatible server
  • Extendable tool system: add servers in `.alecto/config.json` (`mcpServers`)
  • Model selection: pull any model with `ollama pull` (README examples: `ministral:3b`)
  • Simple Makefile development workflow (`make setup` / `build` / `dev` / `install`)

Installation

Prerequisites: Node.js 18+, npm, and Ollama.



# 1. Install Ollama

curl -fsSL https://ollama.com/install.sh | sh



# 2. Download a model

ollama pull ministral:3b



# 3. Install dependencies

make setup

Usage

Start the Ollama server, then the app; type a message and press Enter (`exit` to quit):



ollama serve

npm start

Configuration lives in `.alecto/config.json` — `mcpServers` (per-server `command`/`args`) and `ollama.host` / `ollama.model`. See the README for example MCP server setups (filesystem, gemini-cli, duckduckgo).
