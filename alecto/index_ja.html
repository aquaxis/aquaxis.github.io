Alecto

GitHub:

概要

Alecto（Autonomous Logic Executor for Complex Task Operations）は、ローカルの Ollama LLM と MCP（Model Context Protocol）サーバーを組み合わせた、ツール拡張可能な AI チャット CLI アプリケーションです。

特徴

  • Ollama によるローカル LLM との対話
  • MCP サーバーを通じたツール呼び出し（ファイル操作、Web検索など）
  • 設定ファイルへの MCP サーバー追加による拡張可能なツールシステム

インストール

1. Ollama のインストール:



curl -fsSL https://ollama.com/install.sh | sh

2. モデルのダウンロード:



ollama pull ministral:3b

3. 依存パッケージのインストール:



make setup   # または npm install

構成はプロジェクトルートの `.alecto/config.json` で行います（`mcpServers` にコマンドと引数、`ollama.host` / `ollama.model` を指定）。

使い方



ollama serve   # 別ターミナルで Ollama サーバーを起動

npm start      # アプリケーションを起動

メッセージを入力して Enter で送信、`exit` で終了します。

備考

  • 必要条件: Node.js 18 以上、npm、Ollama
  • ライセンス: ISC
