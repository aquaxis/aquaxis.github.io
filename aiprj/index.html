aiprj

GitHub: https://github.com/aquaxis/aiprj

Overview

aiprj is a project management tool for Claude Code, OpenAI Codex CLI, and other agent CLIs. It deploys AI operation guidelines and a document structure (requirements, design, tasks) to a target directory with a single command, so AI agents work against a consistent set of project documents.

Features

  • Definition of AI operation guidelines and rules (`.aiprj/rules/`)
  • Document structure for requirements, design specifications, and task lists
  • Slash commands for Claude Code (`/setup_ai`, `/ai`, `/update_ai`, `/next_ai`, `/close_ai`)
  • Codex CLI skills (`$setup-ai`, `$ai`, `$update-ai`, `$next-ai`, `$close-ai`) and equivalent commands for other agent CLIs
  • Automatic work log saving to `.aiprj/AI_LOG/yyyy-MM-dd_NNN.md` (sequential, no overwriting; each log embeds the instructions state)

Installation

Setup in the current directory:



curl -fsSL https://raw.githubusercontent.com/aquaxis/aiprj/main/install.sh | sh

Setup in a specified directory:



curl -fsSL https://raw.githubusercontent.com/aquaxis/aiprj/main/install.sh | sh -s -- <directory_name>

Manual setup: clone the repository and run `./install.sh `. The installer creates `.aiprj/` (rules and an `instructions.md` placeholder), `.claude/` commands, `.agent-cli/` commands/config, and `.agents/skills/` for Codex; it never overwrites an existing `.aiprj/instructions.md`. Uninstall with `./install.sh -u `.
