ホーム · AIエージェントツール

aiprj

GitHub: https://github.com/aquaxis/aiprj

概要

aiprj は Claude Code・OpenAI Codex CLI などのエージェントCLI向けプロジェクト管理ツールです。1コマンドでAI運用ガイドライン(運用・コーディング・更新規則)と要件・設計・タスクの文書構造を対象ディレクトリへ展開します。作業ログは `.aiprj/AI_LOG/yyyy-MM-dd_NNN.md` 形式で自動保存され、上書きされません。

特徴

  • AI運用ガイドラインとルール定義(`.aiprj/rules/`)
  • 要件・設計・タスクの3文書構造(`/setup_ai` `/ai` `/update_ai` `/next_ai` `/close_ai`)
  • Claude Code用スラッシュコマンド、Codex CLI用スキル(`$setup-ai` 等)、agent-cli用コマンド
  • 作業ログの自動保存(`yyyy-MM-dd_NNN.md`、連番・上書き禁止)
  • インストール済み `instructions.md` は再実行でも上書きしない安全設計

インストール



curl -fsSL https://raw.githubusercontent.com/aquaxis/aiprj/main/install.sh | sh

# 特定ディレクトリへ:

curl -fsSL https://raw.githubusercontent.com/aquaxis/aiprj/main/install.sh | sh -s -- <directory_name>

使い方

`/setup_ai` で3文書を生成、`/ai` でタスク実行、`/next_ai` で次タスクへ、`/update_ai` で instructions.md 変更の反映、`/close_ai` で作業ログ保存と終了。要件変更は `instructions.md` を編集して `/update_ai` — 3文書は instructions.md を唯一の情報源として整合維持されます。

備考

  • 要件: curl、tar または git、Claude Code / Codex CLI / 互換エージェントCLI
  • デフォルトで `.aiprj` は .gitignore 対象(チーム共有する場合は設定解除)
