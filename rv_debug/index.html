rv_debug

GitHub: https://github.com/aquaxis/rv_debug

Overview

RISC-V debug module RTL (Debug Module / DTM) for JTAG-based on-target debugging. It is the companion debug IP of the `rv_saturn` RISC-V SoC.

Usage

Integrate the debug module RTL alongside the `rv_saturn` core and connect it to OpenOCD over JTAG for interactive debugging.
