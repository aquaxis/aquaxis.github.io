jpegenc_gai

GitHub: https://github.com/aquaxis/jpegenc_gai

Overview

jpegenc_gai is a JPEG encoder IP generated by AI. It is the companion artifact of a published book.

Features

  • Written in SystemVerilog
  • 24-bit RGB input
  • 4:2:0 sampling
  • JPEG header output

Installation

Clone the repository and integrate the RTL into your FPGA build:



git clone https://github.com/aquaxis/jpegenc_gai.git

Usage

The companion book (Japanese) is available on Booth and Tech Book Fest.
