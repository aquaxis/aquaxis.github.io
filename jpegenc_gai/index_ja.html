jpegenc_gai

GitHub: https://github.com/aquaxis/jpegenc_gai

概要

生成AIに書かせたJPEGエンコーダーのIPです。言語はSystemVerilog、入力は24bit RGB、サンプリングは4:2:0、JPEGヘッダ出力あり。

特徴

  • SystemVerilog 実装
  • 24bit RGB 入力 / 4:2:0 サンプリング
  • JPEGヘッダ出力
  • 書籍の成果物

インストール

リポジトリをクローン:

git clone https://github.com/aquaxis/jpegenc_gai.git

使い方

書籍の解説とともに利用します。書籍は Booth / 技術書典 で頒布。
