athena

GitHub: https://github.com/aquaxis/athena

概要

ATHENA (Autonomous Task Hierarchy & Execution Network Architecture) は、自然言語での作業指示を複数の AI エージェント階層(Director / Lead / Worker)で計画・委譲・再計画するシステムアーキテクチャです。HTTP/SSE の Core API、CLI (`athena chat`)、WASM 製 Studio UI を備えます。

特徴

  • AIエージェント自体がコア: Core Host (athena-core) は監督・状態記録・ポリシー強制のみ、思考はエージェントプロセスが担う
  • 5実行ユニット: athena-api (常駐:8080) / athena-core / athena-runtime-agent-cli / athena CLI / athena-studio (WASM:5173)
  • 単一の権威あるストア `athena.db` (redb — 純Rust組み込みACID)
  • `athena init` による人・スキル・設定のプロジェクト配布
  • モジュール境界は CI の静的検査で機械的に強制
  • 仕様書 (`spec/athena_spec_1.0.md`) が唯一の正、全正規文に ATH-* ID

インストール

一行で(ビルドして2バイナリをPATHへ):



curl -fsSL https://raw.githubusercontent.com/aquaxis/athena/main/install.sh | sh

更新は `athena update`(ツール更新+プロジェクトの personas/skills を追加的更新)。

使い方



cd ~/projects/my-project

athena init          # .athena/ と .aiprj/ を生成

athena-api           # 常駐Core API (127.0.0.1:8080)

athena run "TODO APIを実装して"

athena chat          # 会話型エントリポイント

athena status

`.athena/config.yaml` で provider / model / delegable_tools を明示設定(シークレットは書かない)。
