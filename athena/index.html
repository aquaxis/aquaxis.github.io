athena

GitHub: https://github.com/aquaxis/athena

Overview

ATHENA (Autonomous Task Hierarchy & Execution Network Architecture) is a system architecture that organizes multiple AI agents to carry out work requested in natural language. The Core Agent is itself an AI agent: it plans, delegates down a Director/Lead/Worker hierarchy, evaluates results, and re-plans when needed.

Features

  • Five execution units: `athena-api` (HTTP + SSE, port 8080), `athena-core` (Core Host library), `athena-runtime-agent-cli` (adapter + process manager), `athena` (CLI), `athena-studio` (WASM UI, port 5173)
  • Authoritative state in a single `athena.db` (pure-Rust embedded `redb` store, ACID, file-backed)
  • Spec-driven design (`spec/athena_spec_1.0.md`, requirement IDs `ATH-*`); dependency boundaries enforced in CI
  • Per-project setup with `athena init` (generates `.athena/` and expands aiprj scaffolding)
  • Conversational entry point `athena chat` with task progress, inline approvals, and clarifying questions

Installation

One-liner (builds and installs `athena` and `athena-api` onto PATH; requires the Rust toolchain):



curl -fsSL https://raw.githubusercontent.com/aquaxis/athena/main/install.sh | sh

From an existing clone:



./install.sh

# or: cargo build --release   (binaries at ./target/release/)

Usage

Initialize a project and start the Core API, then send work in natural language:



cd ~/projects/my-project

athena init

athena-api

# edit .athena/config.yaml: core.agent.provider / .model / .delegable_tools (explicit, ATH-AGENT-008 / ATH-SEC-024)

athena run "implement the TODO API"

athena status && athena task list

Other commands: `athena chat`, `athena task show/cancel`, `athena plan show`, `athena approval list/approve/reject`, `athena skill list/show/register`; every command accepts `--json`. Secrets come from environment variables or a secret manager, never from `config.yaml` (ATH-CFG-005).

Notes

  • Implementation-status note from the README: some CLI verbs currently print the request they would send to the Core API.
