asuna

GitHub: https://github.com/aquaxis/asuna

Overview

ASUNA (Algorithmic Synthesis for Unified Netlist Automation) is a high-level synthesis tool that generates Verilog HDL from C source code. It takes a deliberately simple approach: C language only, one input source file, and each function becomes a Verilog module.

Features

  • C-to-VerilogHDL high-level synthesis
  • Function = module mapping for a simple, predictable output structure
  • No LLVM front end or back end dependency
  • Single-file input keeps the synthesis scope clear

Installation

Build the tool from the repository sources:



git clone https://github.com/aquaxis/asuna.git

cd asuna

The repository's Makefile builds the toolchain; see the repository README for build instructions and constraints.

Usage

Feed a C source file to generate Verilog HDL. Documented constraints from the repository README:

  • C language only; input is a single source file; comments are expected in Japanese (UTF-8)
  • Complex structures and macros may not be processed
  • Floating point is not supported
  • Division generates very large circuits
  • Structures should be 4-byte aligned
  • Memory is externalized, so initialization cannot happen inside the generated hardware — initialize from outside
