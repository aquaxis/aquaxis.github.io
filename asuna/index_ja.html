asuna

GitHub: https://github.com/aquaxis/asuna

概要

ASUNA(Algorithmic Synthesis for Unified Netlist Automation)は、C言語からVerilogHDLを生成する高位合成ツールです。「単純に、C言語をVerilogHDLに変換する」。関数=モジュールという考え方で設計されています。

特徴

  • C言語のみ対応(LLVMフロントエンド/バックエンド非使用)
  • 入力は1ファイルのみ
  • メモリは外部化(初期化は外部から行う)
  • 4Byteアライメントの構造体に対応
  • 浮動小数点と除算は非対応(除算は莫大な回路を生成)

インストール

ソースをコンパイルしてツールをビルドします:

git clone https://github.com/aquaxis/asuna.git

使い方

C言語ソースを入力に、VerilogHDLを生成します。制約の詳細は リポジトリREADME を参照してください。
