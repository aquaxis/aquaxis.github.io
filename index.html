GitHub: https://github.com/aquaxis

aquaxis is an open-source engineering organization working across two connected fields: AI-driven software and hardware (FPGA/HDL) design automation. All 43 public repositories are presented in the tables below, grouped into four categories; each repository has its own page.

AI & Agent Tools

The AI agent stack: agent-cli is the process/IPC foundation, and athena, layers, mnemo, and hestia build on it. Category page: AI & Agent Tools.
