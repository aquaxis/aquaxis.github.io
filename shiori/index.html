Overview

Shiori is an HDL/RTL annotation ecosystem: by embedding "waymark" annotations into hardware source code, it automates documentation generation, validity checking, testbench generation, and source-code generation. Annotations are Markdown-based and readable by humans, while the `@modifier` syntax gives them structure that AI agents can parse.

Features

  • Human-readable — natural Markdown notation that fits into existing comments with a few extra lines
  • AI-readable — structured `@modifier` syntax, with a dedicated AI reference document (Japanese and English) for agent consumption
  • Four commands: `shiori gen-doc` (Markdown specifications from annotations), `shiori check` (annotation↔source consistency), `shiori gen-tb` (SystemVerilog testbench generation), and `shiori gen-src` (HDL skeleton generation)
  • Language support: SystemVerilog (IEEE 1800-2023, `//` and `/* */`) and IRIS (`//`, `/* */`, `///`, `//!`)
  • 50 modifiers documented in the reference; guides for SystemVerilog and IRIS usage, CLI reference, best practices, and an FAQ

Installation

Shiori is a TypeScript toolchain. Clone the repository and build with the TypeScript toolchain of your choice; the `doc/01-quickstart.md` guide walks through installation and the first run. (See the repository's README and quickstart guide for the exact commands.)

Usage



shiori gen-doc   # generate a Markdown specification from annotations

shiori check     # check annotations against the source code

shiori gen-tb    # generate a SystemVerilog testbench from annotations

shiori gen-src   # generate an HDL source skeleton from annotations

The documentation set (`doc/01-quickstart.md` … `doc/07-faq.md`) covers the quickstart, the full modifier reference, language-specific guides, CLI options, and annotation best practices.
