shiori

GitHub: https://github.com/aquaxis/shiori

概要

栞(Shiori)は、HDL/RTLソースコードに「道標(アノテーション)」を埋め込むことで、ドキュメント生成・妥当性確認・テストベンチ生成・ソースコード生成を自動化するツールです。SystemVerilog(IEEE 1800-2023準拠)とIRISに対応しています。

特徴

  • Markdownで書く、人にもAIにも読めるアノテーション
  • shiori gen-doc — アノテーションからMarkdown仕様書を生成
  • shiori check — アノテーションとソースの整合性チェック
  • shiori gen-tb — SystemVerilogテストベンチ生成
  • shiori gen-src — HDLソース雛形生成
  • 50種類の修飾子とAI向けリファレンスを同梱

インストール

git clone https://github.com/aquaxis/shiori.git

使い方

shiori gen-doc / check / gen-tb / gen-src の各コマンドにソースを渡します。クイックスタート・CLIリファレンス・ベストプラクティスは ユーザガイド(doc/) を参照してください。
