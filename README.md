# aquaxis.github.io

Project pages for the public repositories of the [aquaxis](https://github.com/aquaxis) GitHub organization, published at https://aquaxis.github.io/.

- **English edition**: `index.html` (home) and `<repository>/index.html` per repository
- **Japanese edition**: `index_ja.html` (home) and `<repository>/index_ja.html` per repository
- Four categories: AI & Agent Tools · Hardware & RTL · Embedded & Hardware Applications · Resources & References

The site is plain static HTML — no build step, no client-side JavaScript. Page content is derived from each repository's README and public metadata; documentation and purchase links come from the upstream sources.
