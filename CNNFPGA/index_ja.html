CNNFPGA

GitHub: https://github.com/aquaxis/CNNFPGA

概要

「ソフトウェア技術者のためのFPGA入門 機械学習編」のSDSoC 2017.2ワークフォルダです。リポジトリをクローンし、SDSoCに取り込んで使用します。

特徴

  • SDSoC 2017.2 用のワークフォルダ
  • 起動時に Workspace としてクローン先を指定して使用
  • File > Open Projects from File Systems でプロジェクトを取込み

インストール

リポジトリのクローン後に SDSoC を起動:

git clone https://github.com/aquaxis/CNNFPGA.git

使い方

SDSoC起動時に Workspace として本フォルダを指定し、Import Projects で CNN_Test0〜40 のプロジェクトを取込みます。各ケースは CNN 処理の FPGA 化を段階的に示します(mem_attribute/access_pattern プラグマ、Convolution/Pooling/CNNLayer 関数の FPGA 化、パイプライン/全展開、CNN 全体、ZCU102 ケース)。詳細は リポジトリREADME。
