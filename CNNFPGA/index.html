CNNFPGA

GitHub: https://github.com/aquaxis/CNNFPGA

Overview

Working folder of the book "FPGA introduction for software engineers — machine learning edition": SDSoC 2017.2 projects (CNN_Test0–CNN_Test50) that walk from software-only builds to full FPGA acceleration of the CNN layers, case by case.

Features

  • SDSoC 2017.2 workspace projects for the book's machine-learning exercises
  • Clone or download and import into SDSoC to follow the book step by step
  • Book companion: build the examples exactly as printed

Installation

Clone the repository and open it as the SDSoC workspace:



git clone https://github.com/aquaxis/CNNFPGA.git

Then start SDSoC 2017.2 and select the cloned folder as the workspace (File → Switch Workspace → Other…), and import the projects via File → Open Projects from File Systems….

Usage

Use alongside the book: each project (CNN_Test0–40) is imported into the SDSoC workspace and built as described — the cases step through FPGA-izing the CNN layers (mem_attribute/access_pattern pragmas, Convolution/Pooling/CNNLayer functions, pipelining/unrolling, full CNN, and the ZCU102 case). Requires the SDSoC 2017.2 toolchain (Xilinx).
