ChronoMark

GitHub: https://github.com/aquaxis/ChronoMark

概要

ChronoMark は Markdown でタスクを管理し、ガントチャートで表示する Web アプリです。タスク1件が Markdown ファイル1つで、テキストのまま編集・Gitで履歴管理でき、ブラウザ上でガントチャートとして操作できます。バックエンドは Node.js / TypeScript。

特徴

  • Markdown が唯一の正 — 1タスク=1ファイル、データベースなし、履歴と差分は Git
  • jQueryGantt 本体同梱 — 依存関係・階層・進捗・マイルストーンを直接編集、自動保存
  • プロパティフォームと `.md` 直接編集の2方式、Obsidian風ライブプレビュー
  • 階層はディレクトリ構造そのもの、参照は常に不変な uid(ULID)
  • 外部ツール(jQueryGantt / Redmine / GitHub Projects / Backlog)からの正規化取り込み
  • ファイル変更の検知と全画面への即時反映(WebSocket)

インストール



./setup.sh    # Node.js 20以上の確認、依存インストール、動作確認

npm start     # http://localhost:4000 で起動(データは ./data)

使い方



npm run project:create -- <name>   # プロジェクト作成(再起動不要)

npm run sample:create             # READMEのサンプルデータを作成

npm run import:gantt -- <name>     # jQueryGanttエクスポートを取り込み

起動後は Explorer(タスクツリー)→ 編集画面(フォーム / ライブ `.md`)→ ガントチャートの画面で操作します。全操作は HTTP API 経由で、ブラウザがファイルを直接触ることはありません。
