ModView

GitHub: https://github.com/aquaxis/ModView

Overview

ModView is a SystemVerilog module interconnection viewer: a lightweight, OSS-only web application that parses RTL and draws how modules are wired together as a diagram you can rearrange and save. It needs no commercial RTL viewer licence — point it at a folder of `.sv`/`.v` files and read the design in a browser.

Features

  • Parses with Verible: modules, ports, bus widths, parameters, instances, and connections, including SystemVerilog `interface`/`modport` declarations.
  • Infers wiring from nets, not naming conventions — ports bound to the same signal form a net with one chosen driver; un-uploaded submodules still appear with inferred port directions.
  • Automatic layered left-to-right layout with orthogonal edge routing by ELK.js, so lines avoid node bodies and each other.
  • Shows hierarchy in place: instances containing instances are drawn as nested containers; interface buses collapse into one expandable, colour-coded trunk link.
  • Editable diagrams — drag nodes and every drop re-routes the connections; the layout can be saved as JSON and loaded back (Ctrl+S / Ctrl+O).
  • Bundled example design: a 12-module baseline JPEG encoder connected by AXI4-Stream, used in the repository's walkthrough.

Installation

Quick start with Docker:



docker compose up --build

# Frontend: http://localhost:5173 — backend API: http://localhost:8000

Local development (requires `verible-verilog-syntax` on `PATH`):



# Backend

cd backend

uv venv && uv pip install -e ".[dev]"

uv run uvicorn app.main:app --reload --port 8000



# Frontend

cd frontend

pnpm install --ignore-workspace

pnpm dev    # http://localhost:5173, proxies /api to :8000

Usage

1. Click **Select Folder** and pick a directory of `.sv`/`.v` files (up to 20,000 files, 50 MB each, 500 MB total).

2. Click **Parse** — the sidebar fills with modules and the top-module dropdown groups *Top candidates* vs *Other modules*.

3. Pick a top module and read the diagram; zoom with the wheel or `+`/`−`, frame with **Fit**.

4. Unlock editing to drag nodes (each drop re-routes connections), use **Re-layout** to restore ELK's automatic arrangement, and **Save** the layout as JSON.

Parse errors are non-fatal: modules that still parse are rendered, and the error list opens from the status bar with file, line, and column.
