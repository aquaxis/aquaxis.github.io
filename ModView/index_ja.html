ModView

GitHub: https://github.com/aquaxis/ModView

概要

ModViewは SystemVerilog モジュール接続ビューアです。RTLフォルダを指定すると、Veribleで構文解析し、モジュールの配線図をブラウザ上に描画します。ドラッグで再配置もでき、OSSのみで動作します。

特徴

  • Verible による構文解析(モジュール/ポート/バス幅/パラメータ/インスタンス接続)
  • ネット経由の配線推論(命名規則に依存しない)
  • ELK.js による自動レイアウト(階層配置+直交エッジルーティング)
  • 階層をコンテナノードとしてネスト表示
  • interface バスの色分きトランク表示(クリックで展開/折畳)
  • レイアウトのJSON保存/読込(Ctrl+S / Ctrl+O)

インストール

Docker(推奨):

docker compose up --build

使い方

ブラウザでUIにアクセスし、Select Folder でRTLフォルダを取込み、Parse を押します。付属のJPEGエンコーダ例(example/jpegenc/rtl)で動作確認できます。
