Mnemo

GitHub: https://github.com/aquaxis/mnemo

概要

Mnemo は、Markdown ベースの統合ナレッジデータベースです（「記憶と知識の万能アーカイブ」— 名前は記憶の女神ムネモシュネに由来）。Obsidian 風のライブメモ編集、Wiki、AI エージェントによる Web 収集、AI チャット（リサーチモード）、定期タスクを組み合わせ、すべてを持ち運べる Markdown ファイルとして保存します。

特徴

  • 3ペインUI（ナビゲーション・ノート一覧・エディタ）、デスクトップとモバイル両対応
  • Live Markdown エディタ（CodeMirror 6）— Obsidian 風インラインプレビュー
  • AI情報収集 — Webページをクロールし要点を抽出してノート化
  • AIチャット リサーチモード — 最新の Web 情報を調査してから出典付きで回答、会話はノートとして自動保存
  • お願いするだけで定期タスク化（例: 「毎朝AIニュースを収集して」）— cronScheduler へ自動登録
  • 全ノート対象のAI検索、AIバックエンドの選択（agent-cli または Claude Code CLI — Claude API は不使用）
  • Markdownファーストの保存 — フロントマターなしの素の Markdown、フォルダ階層で分類。アプリ外でもそのまま使える

インストール

ワンライナー:



curl -fsSL https://raw.githubusercontent.com/aquaxis/mnemo/main/install.sh | sh

# 特定ディレクトリへ:

curl -fsSL https://raw.githubusercontent.com/aquaxis/mnemo/main/install.sh | sh -s -- my-mnemo

手動セットアップ:



git clone https://github.com/aquaxis/mnemo.git

cd mnemo

npm install   # Webアプリの依存

npm start     # Webアプリ + Rustサーバーバイナリをビルドして起動

必要条件: Node.js ≥ 18 と Rust（cargo）。更新では `data/`（ノート・設定・定期タスク）は決して破壊されません。

使い方

ブラウザで `http://localhost:3000` を開きます。設定は `data/config.json`（ポート、AIバックエンド `ai.type`、出力言語、Jina AI 検索API等との連携`search.endpoint` と `JINA_API_KEY`、信頼性設定）で行い、アプリ内の Settings ページからも編集できます。デタッチ実行例:



nohup npm start >/dev/null 2>&1 &

データ配置: `data/notes/`（カテゴリ分類されたMarkdown）、`data/assets/`、`data/scripts/`（エージェント作業ファイル）、`data/jobs/`（定期タスク）。

備考

  • 技術スタック: サーバー Rust（axum + tokio）、Webアプリ TypeScript（React + Vite + Tailwind）、エディタ CodeMirror 6
  • ログは `data/logs/mnemo.log` に書かれ、AIバックエンド呼び出しの失敗はチャット返信やタスク実行履歴で可視化されます
