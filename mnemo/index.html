Mnemo

GitHub: https://github.com/aquaxis/mnemo

Overview

Mnemo is an integrated, Markdown-based knowledge database — an "omnipotent archive of memory and knowledge" (named for Mnemosyne, the Greek goddess of memory). It combines Obsidian-style live Markdown note taking, a wiki, AI-agent web collection, AI chat (research mode), and scheduled tasks, storing everything as portable Markdown files.

Features

  • Three-pane UI (navigation · note list · editor) with draggable, collapsible panes; single-screen phone layout below 768px
  • Obsidian-style live Markdown editor (CodeMirror 6); note = file, folder = category, no frontmatter
  • AI information collection: crawl web pages, extract key points, save as notes
  • AI chat (research mode): web-checked answers with source lists; conversations auto-save as notes
  • Schedule tasks by asking ("every morning, collect the AI news") or via the Schedule button; cron scheduling
  • Selectable AI backend: agent-cli (default) or Claude Code CLI; AI note search across all notes

Installation

One-liner:



curl -fsSL https://raw.githubusercontent.com/aquaxis/mnemo/main/install.sh | sh

# or into a specific directory:

curl -fsSL https://raw.githubusercontent.com/aquaxis/mnemo/main/install.sh | sh -s -- my-mnemo

Manual setup:



git clone https://github.com/aquaxis/mnemo.git

cd mnemo

npm install   # web app dependencies

npm start     # builds the web app + Rust server binary, then runs the server

Requirements: Node.js ≥ 18 and Rust (cargo). Updates never touch `data/` (notes, assets, config, and scheduled jobs survive).

Usage

Open `http://localhost:3000` in a browser. Configuration is in `data/config.json` (port, AI backend via `ai.type`, output language, search endpoint such as the Jina AI search API with `JINA_API_KEY`, reliability settings). Settings can also be edited from the in-app Settings page. For running it detached:



nohup npm start >/dev/null 2>&1 &

Data layout: `data/notes/` (Markdown, classified by category), `data/assets/`, `data/scripts/` (agent working files), `data/jobs/` (scheduled jobs).

Notes

Tech stack: Rust (axum + tokio) server; TypeScript (React + Vite + Tailwind) web app with CodeMirror 6.
