rag-cli

GitHub: https://github.com/aquaxis/rag-cli

概要

rag-cli は、単一の Rust バイナリで動作する完全ローカルの RAG（検索拡張生成）システムです。Hono 互換の REST API（`127.0.0.1:7777`）と CLI を備え、Node.js ランタイムは不要です。

特徴

  • **多形式のオフライン取り込み** — PDF / 画像 / SVG / drawio / Markdown / プレーンテキスト / Web URL
  • **多言語埋め込み** — `bge-m3`（1024次元、Ollama / llama.cpp を切替）
  • **ベクトル検索** — Qdrant v1.12.4 + HNSW Cosine + payload インデックス
  • **クロスエンコーダ リランカー** — `bge-reranker-v2-m3-ONNX`（`ort` + `tokenizers` + `hf-hub`）
  • **LLM回答** — `qwen2.5:7b-instruct`（出典引用 `[1][2]` 付き、不明点は明示）
  • **日本語対応チャンキング** — 句読点優先の再帰分割 + 見出しパス接頭辞
  • **単一バイナリ配布** — `cargo install` または `cargo build --release`（Node.js 不要）

インストール



cargo build --release            # ./target/release/rag-cli

cargo install --path crates/cli  # ~/.cargo/bin/rag-cli

外部サービス（Qdrant / Ollama / Docling Serve）は `podman compose up -d` で起動します。モデルは次のコマンドで取得:



podman exec rag-ollama ollama pull bge-m3

podman exec rag-ollama ollama pull qwen2.5:7b-instruct

詳細はリポジトリの `doc/01-installation.md` を参照してください。

使い方



rag-cli ingest data/md/note.md      # 取り込み（ファイル/ディレクトリ/URL）

rag-cli search "質問文" --top-n 3 --no-rerank

rag-cli serve                       # REST API 起動（127.0.0.1:7777）

rag-cli status / reindex

REST API は `/health`、`/ingest`、`/ingest/upload`、`/search`、`/search/stream`、`/status`、`/reindex` の7エンドポイントを提供します。

備考

  • 既定では `127.0.0.1` バインド（LAN・公開時は認証付きリバースプロキシを使用）
  • 設定は `.env`（24環境変数、`doc/05-configuration.md` 参照）
