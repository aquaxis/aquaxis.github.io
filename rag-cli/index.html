rag-cli

GitHub: https://github.com/aquaxis/rag-cli

Overview

A self-contained, standalone local RAG (Retrieval-Augmented Generation) system built as a single Rust binary with an Hono-compatible REST API (`127.0.0.1:7777`) and a CLI. No Node.js runtime required.

Features

  • Multi-format offline ingestion: PDF / images / SVG / drawio / Markdown / plain text / web URLs
  • Multilingual embeddings: `bge-m3` (1024 dim, switchable between Ollama / llama.cpp)
  • Vector search: Qdrant v1.12.4 + HNSW Cosine + payload index
  • Cross-encoder reranker: `bge-reranker-v2-m3-ONNX` (`ort` + `tokenizers` + `hf-hub`)
  • LLM answer generation with source citations (`qwen2.5:7b-instruct`)
  • Japanese-aware chunking: punctuation-prioritized recursive splitting + heading path prefixes
  • REST API: `/health`, `/ingest`, `/ingest/upload`, `/search`, `/search/stream`, `/status`, `/reindex`

Installation

Build a local binary:



cargo build --release        # -> ./target/release/rag-cli

Install system-wide:



cargo install --path crates/cli    # -> ~/.cargo/bin/rag-cli

Start the external services (optional, via Podman):



podman compose up -d

podman exec rag-ollama ollama pull bge-m3

podman exec rag-ollama ollama pull qwen2.5:7b-instruct

Configuration is via environment variables in `.env` (copy from `.env.example`); defaults bind to `127.0.0.1` and are sufficient to start. The first reranked search downloads the reranker model (~600 MB).

Usage



rag-cli ingest data/md/note.md

rag-cli search "What is the summary of the sample memo?" --top-n 3 --no-rerank

rag-cli serve --port 7777

rag-cli status

rag-cli reindex

The full workflow and model pull steps are in the repository's `doc/02-quickstart.md`; CLI details in `doc/03-cli.md`, REST API in `doc/04-rest-api.md`, and configuration in `doc/05-configuration.md`.
