meta-aquaxis

GitHub: https://github.com/aquaxis/meta-aquaxis

概要

Ultra96V2 用の Yocto Project レイヤー(meta-aquaxis)。PMU ファームウェア・Linux ディストリビューション・SDカードイメージ・SDK の構成を提供します。

特徴

  • Ultra96V2 対応レシピ/構成
  • PMU ファームウェア・core-image-minimal ビルド手順
  • SDカードイメージ生成(mkbootbin/mksdcard スクリプト)
  • SDK 生成(populate_sdk)

インストール

Yocto ビルド環境の作成とビルド:

git clone https://github.com/aquaxis/meta-aquaxis.git
./meta-aquaxis/create_env.sh
source ./poky/ oe-init-build-env ../build_pmu-firmware/
