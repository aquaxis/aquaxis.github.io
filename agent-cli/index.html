agent-cli

GitHub: https://github.com/aquaxis/agent-cli

Overview

agent-cli is a standalone Rust CLI that bundles a Claude Code-equivalent AI agent (tools / thinking / streaming REPL) into a single binary, without depending on tmux. Each process owns exactly one agent and talks to other agents over local Unix-domain-socket IPC.

Features

  • Claude Code-equivalent REPL with built-in tools and thinking, implemented from scratch
  • Nine backends: `claude` / `claude-code` / `codex` / `codex-code` / `strata` / `ollama` / `opencode` / `opencode-go` / `llama.cpp`
  • Multi-agent coordination via `/send` (report without a turn, or ask that waits for the answer)
  • Detached agents (`spawn`/`stop`), groups, and persona files (YAML frontmatter + Markdown)
  • Per-call permission rules in `[permissions]` (deny/allow lists of `tool(pattern)` rules)
  • Custom slash commands, MCP client support, shell `! ` commands, mouse select/copy, scriptable one-shot/ask modes

Installation

One-liner:



curl -fsSL https://raw.githubusercontent.com/aquaxis/agent-cli/main/install.sh | sh

Build from source:



git clone https://github.com/aquaxis/agent-cli.git

cd agent-cli

cargo install --path . --root "$HOME/.local"

Usage

Start the REPL: `agent-cli` (or `agent-cli run --provider claude`). Set the API key for your backend first, e.g. `export ANTHROPIC_API_KEY=...`. Useful subcommands: `spawn`, `ask`, `one-shot`, `list`, `doctor`, `selftest`.

Scripted use: `echo "prompt" | agent-cli run`, or ask a running peer: `agent-cli ask "..."`. Inspect the config in force with `agent-cli config path`; sanity-check the installation with `agent-cli doctor`.

Notes

  • Linux (x86_64 / aarch64); self-update via `agent-cli update`; docs under `doc/`.
