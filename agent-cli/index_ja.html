agent-cli

GitHub: https://github.com/aquaxis/agent-cli

概要

agent-cli は、Claude Code 相当の AI エージェント REPL を 1 バイナリにまとめたスタンドアロンの Rust CLI です。組み込みツール、9 種類のプロバイダバックエンド、マルチエージェント IPC、ペルソナ/グループ/デタッチド・エージェントを備えます。

特徴

  • スタンドアロン — tmux不要、単一バイナリで動作
  • 9バックエンド(claude codex ollama opencode llama.cpp strata など)
  • UnixソケットIPCによるマルチエージェント連携 (`/send` `/ask`)
  • デタッチドエージェント (`spawn` / `stop`) とグループ管理
  • ペルソナファイル(YAML+Markdown)による役割定義
  • パーミッションルール(deny/allow)とレイヤード設定(TOML)
  • カスタムスラッシュコマンド、MCPクライアント対応

インストール

一行で:



curl -fsSL https://raw.githubusercontent.com/aquaxis/agent-cli/main/install.sh | sh

ソースから:



git clone https://github.com/aquaxis/agent-cli.git

cd agent-cli

cargo install --path . --root "$HOME/.local"

Linux (x86_64 / aarch64) 向け。設定は `~/.config/agent-cli/config.toml` に初回起動時に自動生成されます。

使い方



agent-cli                          # REPL起動(provider.kind を使用)

agent-cli run --provider ollama     # バックエンド指定

agent-cli spawn --name worker      # デタッチドエージェント

agent-cli ask worker "質問文"      # 起動済みエージェントへ一問一答

agent-cli doctor                   # セルフ診断

REPL 内では `/send` `/spawn` `/list` `/auto on` などのコマンド、プロンプトへは `! ` でシェル直実行が使えます。
