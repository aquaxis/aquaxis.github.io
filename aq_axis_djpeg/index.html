aq_axis_djpeg

GitHub: https://github.com/aquaxis/aq_axis_djpeg

Overview

AXIS JPEG Decoder is a JPEG baseline decoder IP with JPEG stream input and blocked pixel-stream output, both using AXI-Stream interfaces, and an AXI-Lite monitoring interface. It is designed for decoding baseline JPEG images as well as the first layer of progressive JPEGs.

Features

  • ISO/IEC 10918-1 compliant JPEG baseline decoding
  • Supports up to 64K × 64K image resolution
  • Dynamic quantization and Huffman tables; automatic JPEG header extraction for tables and image properties
  • Supports YCbCr 4:4:4, 4:2:2H, 4:2:2V, 4:2:0 and monochrome inputs, plus first-layer progressive extraction, DRI labels and restarts
  • I/O AXI-Stream interfaces with full flow control, and an AXI-Lite monitoring interface

Installation

Clone the repository and add the RTL to your Vivado project:



git clone https://github.com/aquaxis/aq_axis_djpeg.git

Usage

Provide a JPEG data stream on the AXI-Stream input interface; the pixel stream and pixel position stream are extracted through the AXI-Stream output's TDATA and TUSER channels. Image size, color components, and baseline/progressive information are extracted automatically from the JPEG header. Refer to the repository README for integration details.

Notes

  • Language: Verilog.
