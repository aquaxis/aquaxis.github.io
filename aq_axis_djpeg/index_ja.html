aq_axis_djpeg

GitHub: https://github.com/aquaxis/aq_axis_djpeg

概要

AXIS JPEG Decoder — JPEGベースラインデコーダーIP。JPEGストリーム入力とAXI-Streamによるブロック化ストリーム出力、AXI-Lite監視インターフェースを持つAXI-Stream IP です。

特徴

  • ISO/IEC 10918-1 準拠のJPEGベースラインデコード
  • 最大64K x 64K 解像度対応
  • 動的量ビット・ハフマンテーブル
  • JPEGヘッダ automatic 抽取、YCbCr 4:4:4/4:2:2H/4:2:2V/4:2:0/モノクロ対応
  • プログレッシブJPEGの第一層デコード対応
  • I/O AXI-Stream(フロー制御付き)+AXI-Lite監視

インストール

リポジトリをクローン:

git clone https://github.com/aquaxis/aq_axis_djpeg.git

使い方

Vivadoプロジェクトへの取込み方は リポジトリREADME を参照してください。
