c105

GitHub: https://github.com/aquaxis/c105

Overview

Sample source code of the C105 doujinshi book on FPGA development (chapters: first FPGA development, beacon circuit, and RISC-V). The PDF edition is sold on Booth.

Features

  • Complete sample RTL per chapter: adder (ch. 7), beacon circuit (ch. 10), and RISC-V (ch. 11)
  • Vivado build setups: Makefile-driven logic synthesis, place & route, and bitstream generation scripts
  • Constraints (`xdc`) and testbenches included for each design

Installation

Clone the repository and build a chapter with its Makefile:



git clone https://github.com/aquaxis/c105.git

cd c105/01_adder/build

make

Requires Xilinx Vivado (the `vivado` command must be on `PATH`).

Usage

Each chapter folder (`01_adder`, …) contains `rtl/`, `build/`, and `script/`: edit the RTL, run `make` in the chapter's `build/` directory, and write the generated bitstream to your FPGA board as described in the book.
