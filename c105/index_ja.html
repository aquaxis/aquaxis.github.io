c105

GitHub: https://github.com/aquaxis/c105

概要

C105で頒布した書籍「FPGAの内容が薄い本8 やりなおしからはじめるFPGA開発」のサンプルソースコード集です。書籍のPDF版は Booth で頒布中です。

特徴

  • 章ごとの完全なサンプルRTL:アダー(第7章)、ビーコン回路(第10章)、RISC-V(第11章)
  • Vivadoビルド設定:Makefileベースの論理合成・配置配線・ビットストリーム生成スクリプト
  • 各設計に制約ファイル(xdc)とテストベンチを同梱

インストール

リポジトリをクローンし、章のMakefileでビルドします:



git clone https://github.com/aquaxis/c105.git

cd c105/01_adder/build

make

Xilinx Vivado が必要です(vivado コマンドが PATH 上にあること)。

使い方

各章フォルダ(01_adder など)は rtl/・build/・script/ を含みます。RTLを編集し、章の build/ ディレクトリで make を実行し、生成したビットストリームを書籍の記述に従ってFPGAボードへ書き込みます。
