vsync

GitHub: https://github.com/aquaxis/vsync

概要

VSync(V RISC-Vertical SYNC)は、リアルタイムOS(RTOS)をハードウェアで実装し、POSIXインターフェースを備えたRISC-V RV32IMプロセッサシステムです。SystemVerilogで記述され、Xilinx Artix UltraScale+ および Artix-7 をターゲットとします。

特徴

  • RISC-V RV32IM — 5段パイプライン(Fetch/Decode/Execute/Memory/Writeback)
  • タスク管理・スケジューリング・コンテキストスイッチをハードウェアで実装
  • pthread/セマフォ/ミューテックス/メッセージキュー/ファイルI/O をハードウェアレベルでサポート
  • AXI4 → APB ブリッジによるペリフェラル接続(UART, GPIO, HyperRAM, PLIC, CLINT)
  • PMP(Physical Memory Protection)内蔵
  • UART経由のプログラムロード(load/go コマンド)

インストール

リポジトリをクローンし、Vivadoプロジェクトを使用します:

git clone https://github.com/aquaxis/vsync.git
