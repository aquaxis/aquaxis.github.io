vsync

GitHub: https://github.com/aquaxis/vsync

Overview

VSync (RISC-**V**ertical **SYNC**) is an FPGA-targeted RISC-V RV32IM SoC with a real-time OS implemented in hardware and a POSIX-style interface at the hardware level. SystemVerilog design targeting Xilinx Artix UltraScale+ and Artix-7.

Features

  • **RISC-V RV32IM**: 5-stage pipeline (Fetch/Decode/Execute/Memory/Writeback)
  • **Hardware RTOS**: task management, scheduling, and context switching implemented in hardware
  • **POSIX compatible**: pthread, semaphore, mutex, message queue, and file I/O supported at hardware level
  • **Bus architecture**: AXI4 → APB bridge for peripheral connection
  • **Peripherals**: UART, GPIO, HyperRAM, PLIC, CLINT
  • **Memory protection**: PMP (Physical Memory Protection) unit
  • **UART program loading**: `load`/`go` shell commands for program download via UART

Installation

Clone the repository and build with Vivado:



git clone https://github.com/aquaxis/vsync.git

cd vsync

Use the provided Vivado project/scripts for Artix UltraScale+ or Artix-7 targets (see the repository README for build details).

Usage

Work the RTL in Verilator/Vivado simulation, load programs over the UART shell (`load`/`go`), and develop POSIX-style multithreaded applications against the hardware RTOS. See the repository README for the full workflow.
