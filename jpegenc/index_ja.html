jpegenc

GitHub: https://github.com/aquaxis/jpegenc

概要

FPGAベースラインJPEGエンコーダー(SystemVerilog)。低レイテンシかつ高スループットなハードウェアJPEG圧縮を目的とし、RGB画像をJFIF準拠のJPEG出力します。

特徴

  • Dual Processing Pipeline アーキテクチャ
  • 4:2:0 モードで 1.53 clk/px（0.652 px/clk）
  • FHD 1920x1088 @250MHz で推定約78 fps(60fps目標を30%マージンで達成)
  • 全59テスト PASS

インストール

リポジトリをクローン:

git clone https://github.com/aquaxis/jpegenc.git
