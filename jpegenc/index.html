jpegenc

GitHub: https://github.com/aquaxis/jpegenc

Overview

jpegenc is an FPGA baseline JPEG encoder IP written in SystemVerilog. It compresses RGB images in real time and outputs a JFIF-compliant byte stream.

Features

  • Dual Processing Pipeline architecture: 4:2:0 mode at **1.53 clk/px** (0.652 px/clk)
  • ~78 fps estimated at FHD 1920×1088 @ 250 MHz — a 30% margin over a 60 fps target
  • YCbCr RGB input with 4:2:0 sampling and JFIF-compliant output
  • All 59 tests pass
  • Simulator choice: Verilator or Vivado xsim

Installation

Clone the repository and use the supplied simulation/build flow:



git clone https://github.com/aquaxis/jpegenc.git

cd jpegenc

Usage

The repository README documents the file structure, required environment (Vivado / Verilator), the module list, test results, and troubleshooting. Use it as the integration reference for adding the encoder IP to a design.
