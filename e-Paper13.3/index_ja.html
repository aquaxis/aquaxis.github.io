e-Paper13.3

GitHub: https://github.com/aquaxis/e-Paper13.3

概要

Raspberry Pi 上で13.3インチの e-Paper ディスプレイに画像を表示する C 言語プログラムです。BCM2835 ライブラリを利用してハードウェアを直接制御します。

特徴

  • 13.3インチ e-Paper 対応、BMP/PNG 画像読込み表示
  • 6色 カラー表示対応
  • 割込み処理(Ctrl+C)による安全な終了処理
  • 依存: libpng、BCM2835 ライブラリ

インストール

依存ライブラリのインストール後にビルドします:

sudo apt-get install -y libpng-dev build-essential
make

使い方

管理者権限で実行し、画像ファイル(BMP/PNG)へのパスを渡します(例: sudo ./epd path/to/image.png。BCM2835 ライブラリの仕様上 sudo が必要)。終了時(正常終了・Ctrl+C 含む)はディスプレイ保護のため自動的にスリープモードへ移行します。
