e-Paper13.3

GitHub: https://github.com/aquaxis/e-Paper13.3

Overview

A Raspberry Pi C program that displays BMP and PNG images on a 13.3-inch six-color e-Paper display, controlling the panel directly through the BCM2835 library.

Features

  • Drives a 13.3-inch six-color e-Paper display through the BCM2835 library
  • Displays BMP and PNG image files
  • Ctrl+C interrupt handling moves the panel to sleep mode on exit

Installation

Install libpng and build tools, then the BCM2835 library per its official site, and build with the repository Makefile:



sudo apt-get update

sudo apt-get install -y libpng-dev build-essential

Usage

Build and run the display program with the repository Makefile; requirements are a BCM2835-capable Raspberry Pi, the display, GCC, the BCM2835 library, and libpng.
