layers

GitHub: https://github.com/aquaxis/layers

Overview

Layers (Logic Aligned Yet Expressive Role System) is a hierarchical multi-agent system for a game/software development organization: 14 AI agents (Producer, Director, leads, designers, programmers, QA) collaborate, running on tmux + Claude Code CLI or on standalone agent-cli processes.

Features

  • 14 hierarchical agents: Executive (Producer, Director), Design (lead + 2), Programming (lead + 5), QA (lead + 2)
  • Dual backend support: Claude Code CLI (tmux send-keys) or agent-cli (send_to IPC, persona files)
  • Real-time monitoring: health monitoring (`pnpm run monitor`) and a live dashboard of all 14 agents (`pnpm run live`)
  • Inter-agent messaging CLI: `pnpm run send -- --to producer --type instruction --message "Start the project"`
  • Provider selection for the agent-cli backend: claude (default), ollama, codex, opencode, llama.cpp

Installation

Prerequisites: Git, Node.js 20 LTS, pnpm; tmux + Claude Code CLI for the claude backend, or agent-cli for the agent-cli backend. One-liner:



curl -fsSL https://raw.githubusercontent.com/aquaxis/layers/main/install.sh | sh

Manual:



git clone https://github.com/aquaxis/layers.git

cd layers

pnpm install && pnpm run build

pnpm run status   # health check

Usage



pnpm run start                          # all 14 agents (Claude CLI backend, default)

pnpm run start -- --backend agent-cli   # agent-cli backend (--provider ollama etc.)

pnpm run send -- --to producer --type instruction --message "..."

pnpm run live                           # real-time dashboard

pnpm run stop                           # stop all agents

Configuration lives in `.layers/src/config/agents.json`; the agent-cli backend uses persona files in `.layers/personas/` and `.layers/agent-cli.toml`. On Windows use WSL2.

Notes

  • Context limits: 14 simultaneous agents generate significant API usage; run only the agents you need, and use approval skips cautiously in production.
