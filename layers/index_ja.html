Layers

GitHub: https://github.com/aquaxis/layers

概要

Layers（Logic Aligned Yet Expressive Role System）は、ゲーム・ソフトウェア開発組織の組織構造を模した14エージェントの階層型マルチエージェントシステムです。tmux + Claude Code CLI、または agent-cli のスタンドアロンプロセスをバックエンドとして実行できます。

特徴

  • **デュアルバックエンド** — Claude Code CLI（tmux）または agent-cli（スタンドアロンプロセス）でエージェントを実行
  • **14の階層エージェント** — Producer / Director / リード3名（設計・プログラム・QA）/ 下位ワーカーで構成される開発組織構造
  • **エージェント間通信** — tmux send-keys（Claude CLI）または send_to ツール（agent-cli IPC）
  • **リアルタイム監視** — 全エージェントの状態と最新アクティビティを表示するダッシュボード（`pnpm run monitor` / `pnpm run live`）
  • **依存の自動インストール** — Node.js、pnpm、tmux、必要に応じて agent-cli を自動導入

インストール



curl -fsSL https://raw.githubusercontent.com/aquaxis/layers/main/install.sh | sh

手動の場合:



git clone https://github.com/aquaxis/layers.git

cd layers

pnpm install

pnpm run build

pnpm run status

前提条件: Git、Node.js 20.x LTS 以降、pnpm。Claude CLI バックエンドには tmux 3.x 以上と Claude Code CLI、agent-cli バックエンドには agent-cli が必要です。Windows では WSL2 を使用してください。

使い方



pnpm run start                          # Claude Code CLI バックエンド（既定）

pnpm run start -- --backend agent-cli   # agent-cli バックエンド

pnpm run stop                           # 全エージェント停止

pnpm run status                         # 状態確認

pnpm run live                           # リアルタイムダッシュボード

エージェント構成は `.layers/src/config/agents.json`、agent-cli バックエンドのペルソナは `.layers/personas/*.md`（YAMLフロントマター + 本文）で定義します。
