gemac

GitHub: https://github.com/aquaxis/gemac

Overview

gemac is a Gigabit Ethernet MAC with a UDP/TCP/IP offload engine, implemented in Verilog with AXI-Stream based I/O interfaces. The repository currently provides the IP without a README, so details will be documented as the repository's documentation is published.
