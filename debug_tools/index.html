debug_tools

GitHub: https://github.com/aquaxis/debug_tools

Overview

Debug tools for FPGA: Linux utilities that read and write physical memory through `/dev/mem`, used to inspect and modify registers of an FPGA design from a running Linux host.

Features

  • memdump — dump physical memory through /dev/mem
  • memwrite — write values to physical addresses
  • For inspecting and modifying FPGA registers from a running Linux host

Installation



gcc -o memdump memdump.c

gcc -o memwrite memwrite.c

Usage



./memdump ADDRESS(hex) NUM(dec)   # dump NUM words from ADDRESS

./memwrite ADDRESS(hex) DATA(hex) # write DATA to ADDRESS
