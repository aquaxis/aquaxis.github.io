reTerminal

GitHub: https://github.com/aquaxis/reTerminal

概要

XIAO-ESP32-S3 を使用して reTerminal E1002 の7.3インチ e-Paper ディスプレイ(GDEP073E01)を制御する ESP-IDF アプリケーションです。

特徴

  • GDEP073E01(7.3インチ E-Ink Spectra6 フルカラーePaper、800x480px)対応
  • XIAO-ESP32-S3 マイコンボード対応
  • ESP-IDF v5.0 以降 / 3.3V(USB-C)電源

インストール

ESP-IDF の環境構築後、ビルドします:

git clone https://github.com/aquaxis/reTerminal.git
cd reTerminal
idf.py set-target esp32s3
idf.py build

使い方

idf.py -p /dev/ttyUSB0 flash monitor で書込み・動作確認を行います。WiFi設定は SDカード上の config ファイル(SSID/PASSWORD等)で行い、接続後は ESP32 上で HTTPサーバーが自動起動し、ブラウザからファイル一覧・アップロード・e-Paper表示更新(POST /api/update)を利用できます。
