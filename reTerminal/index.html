reTerminal

GitHub: https://github.com/aquaxis/reTerminal

Overview

An ESP-IDF application that drives the reTerminal E1002's 7.3-inch full-color e-Paper display (GDEP073E01, Spectra 6) with a XIAO-ESP32-S3 board.

Features

  • XIAO-ESP32-S3 drives the reTerminal E1002 7.3-inch Spectra6 e-Paper (GDEP073E01, 800x480)
  • ESP-IDF (v5.x) project with GPIO pin map for SPI connection
  • WiFi with DHCP/static IP from an SD-card config file; HTTP server on port 80
  • Browse/upload/download files on the SD card from a browser; POST /api/update refreshes the display

Installation

Requires ESP-IDF v5.0 or later and Python 3.8+:



git clone <repository-url>

cd reTerminal

idf.py set-target esp32s3

idf.py menuconfig   # optional settings

idf.py build

Usage

Flash to the board and display BMP images on the e-Paper panel. Hardware: XIAO-ESP32-S3 + reTerminal E1002 (7.3-inch e-Paper), 3.3 V over USB-C.
