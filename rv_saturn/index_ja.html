rv_saturn

GitHub: https://github.com/aquaxis/rv_saturn

概要

RISC-V Saturn は、RISC-VソフトコアとSoC・デバッグ・FPGA実装一式から成るプロジェクトです。デュアルハート構成のマルチコアで、名称は土星(Saturn)のリングに由来します。

特徴

  • RV32I + RVV(Zve32xサブセット)実装、単一ステージコア
  • デュアルハート — 各ハートが専有IMEM/DMEM、周辺バスのみ共有(ラウンドロビン調停)
  • APB周辺: UART(GPIO内蔵)/QSPI/I2C/タイマ/PLIC/ハードウェアミューテックス
  • AMD(Xilinx) Artix-7(Arty A7)向けFPGA実装一式
  • Verilator RTLシミュレーションとOpenOCDによるJTAGデバック環境
  • Dhrystone 22.059 DMIPS(0.662 DMIPS/MHz)/CoreMark 0.366 CoreMark/MHz(33.33MHz・-Oなし)

インストール

ツールチェーン(RISC-V GCC)とMakeベースのビルド:

git clone https://github.com/aquaxis/rv_saturn.git
cd rv_saturn
make -C apps gpio           # アプリのビルド
make -C sim sim_fpga_verilator SCENARIO=gpio  # Verilatorシミュレーション

使い方

シミュレーションは sim/ フロー([SIM] PASS が正常終了)、FPGAビルドは fpga/ の make artya7(またはトップMakefileのターゲット)で実行します。OpenOCDによるJTAGデバックは simocd/ を参照。
