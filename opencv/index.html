opencv

GitHub: https://github.com/aquaxis/opencv

Overview

opencv is a fork of OpenCV (Open Source Computer Vision Library), the open source computer vision and machine learning software library. This fork is maintained here for aquaxis use; upstream documentation and releases remain the source of truth.

Notes

  • Fork of opencv/opencv — Open Source Computer Vision Library
  • OpenCV is released under the Apache 2 license; upstream documentation applies
