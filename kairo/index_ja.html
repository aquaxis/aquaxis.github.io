kairo

GitHub: https://github.com/aquaxis/kairo

概要

KAIRO(Kernel Architecture with Intelligent RISC-V Operations)は、柔軟性と性能を重視したモジュラーRISC-Vプロセッサコアです。名称は「回路」に由来します。

特徴

  • Modular RISC-V アーキテクチャ
  • SystemVerilog 実装
  • 設定可能で拡張性のある設計
  • 性能と電力効率の最適化

インストール

リポジトリをクローンしてRTLを流用します:

git clone https://github.com/aquaxis/kairo.git

使い方

コアとしての統合方法・モジュール構成は リポジトリREADME を参照してください。
