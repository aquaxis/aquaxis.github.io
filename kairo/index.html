kairo

GitHub: https://github.com/aquaxis/kairo

Overview

KAIRO — Kernel Architecture with Intelligent RISC-V Operations: an advanced RISC-V processor core designed for flexibility and performance. The name derives from the Japanese word for "circuit".

Features

  • Modular RISC-V architecture
  • SystemVerilog implementation
  • Configurable and extensible design
  • Optimized for both performance and power efficiency

Installation

Clone the repository and integrate the RTL into your FPGA/ASIC build:



git clone https://github.com/aquaxis/kairo.git

Usage

See the repository README for the current integration status and module list. The core is provided as reusable RTL modules for Vivado- or Verilator-based design flows.
