aq_axis_fifo

GitHub: https://github.com/aquaxis/aq_axis_fifo

概要

AXI-Stream FIFO(AXI Slave FIFO)のビルディングブロックIPです。

インストール

シミュレーションは Vivado 2024.2 の環境で、sim/ ディレクトリで実行します:

git clone https://github.com/aquaxis/aq_axis_fifo.git
cd aq_axis_fifo/sim
make

使い方

Vivado 2024.2 を前提に、sim/ のMakefileでシミュレーションします。
