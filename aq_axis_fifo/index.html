aq_axis_fifo

GitHub: https://github.com/aquaxis/aq_axis_fifo

Overview

A FIFO with an AXI-Stream slave interface — a building-block IP for stream-based designs.

Features

  • AXI-Stream slave FIFO

Installation

Clone the repository and copy the RTL into your project:



git clone https://github.com/aquaxis/aq_axis_fifo.git

Usage

Simulation requires Vivado 2024.2:



cd sim

make
