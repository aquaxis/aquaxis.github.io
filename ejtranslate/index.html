ejtranslate

GitHub: https://github.com/aquaxis/ejtranslate

Overview

A small Rust CLI that translates between English and Japanese using a local [Ollama](https://ollama.com) server. The source language is detected from the input file, and the model translates into the opposite language.

Features

  • Automatic source-language detection (Hiragana/Katakana/Kanji → Japanese; anything else → English)
  • Any Ollama model selectable with `-m`/`--model`; documented models: `translategemma:12b` (default), `translategemma:4b`, `transgemma:e4b`
  • Output path derived automatically (`notes.md` → `notes_en.md` / `notes_ja.md`) or given explicitly
  • Configurable Ollama host via `-H`/`--host` or `$OLLAMA_HOST`

Installation

One-liner (builds from source via `cargo install`):



curl -fsSL https://raw.githubusercontent.com/aquaxis/ejtranslate/main/install.sh | sh

Alternatives:



cargo install --git https://github.com/aquaxis/ejtranslate ejtranslate

# or from a local checkout:

git clone https://github.com/aquaxis/ejtranslate.git

cd ejtranslate

cargo install --path .

Prerequisites: Rust toolchain (stable, 1.75+) and a running Ollama server with the model pulled:



ollama pull translategemma:12b

Usage



ejtranslate notes.md                     # Japanese input -> notes_en.md

ejtranslate hello.md hello.ja.md         # English input -> explicit output path

ejtranslate notes.md --overwrite         # replace an existing output file

OLLAMA_HOST=http://my-ollama:11434 ejtranslate notes.md
