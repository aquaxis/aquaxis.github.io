ejtranslate

GitHub: https://github.com/aquaxis/ejtranslate

概要

ejtranslate はローカル Ollama サーバを使って英語と日本語を相互翻訳する小型の Rust CLI です。入力ファイルの言語を自動判定(ひらがな・カタカナ・漢字の走査)し、反対の言語へ翻訳します。既定モデルは `translategemma:12b`。

特徴

  • ソース言語の自動検出と反対言語への翻訳
  • モデル選択対応: `translategemma:12b`(既定)/ `translategemma:4b` / `transgemma:e4b` ほか任意の Ollama モデル
  • 出力先の自動命名(`notes.md` → `notes_en.md` / `notes_ja.md`)
  • リモート Ollama サーバ指定(`-H` / `$OLLAMA_HOST`)と上書きオプション(`-w`)

インストール



curl -fsSL https://raw.githubusercontent.com/aquaxis/ejtranslate/main/install.sh | sh

# または cargo で直接:

cargo install --git https://github.com/aquaxis/ejtranslate ejtranslate

使い方

事前に `ollama serve` とモデル取り込み(`ollama pull translategemma:12b`)が必要です。



ejtranslate notes.md              # 日本語 → notes_ja.md へ自動判定翻訳

ejtranslate hello.md hello.ja.md  # 出力先を明示

ejtranslate -m translategemma:4b notes.md

ejtranslate notes.md --overwrite  # 既存出力を上書き

備考

  • 要件: Rust 1.75+、稼働中のローカル Ollama サーバ、翻訳モデル
