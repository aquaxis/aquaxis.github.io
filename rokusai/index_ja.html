rokusai

GitHub: https://github.com/aquaxis/rokusai

概要

rokusai(六彩)は、画像をデジタルフォトフレーム用の7色パレット(黒・白・黄・赤・青・緑)に変換するC言語アプリケーションです。JPEG/PNG をBMP/PNG 形式で出力します。

特徴

  • JPEG/PNG 入力、BMP/PNG 出力
  • グレーワールド法による自動ホワイトバランス、RGBゲインの手動調整
  • 彩度・コントラスト・明度・ガンマ・色相の色強調処理
  • Floyd-Steinberg ディザリング
  • アスペクト比保持リサイズ(白背景での中央配置)

インストール

ビルド方法:

依存ライブラリ(Ubuntu/Debian): libpng-dev、libjpeg-dev。make check-deps で確認できます。

git clone https://github.com/aquaxis/rokusai.git
cd rokusai
make

使い方

既定の自動ホワイトバランスで変換:

./rokusai photo.jpg -a

彩度・コントラスト・ガンマ調整の例:

./rokusai photo.png -s 1.5 -c 1.2 -G 0.9

オプション(-f 出力形式、-r/-g/-b WBゲイン、-w/--height リサイズ等)はリポジトリREADMEを参照してください。
