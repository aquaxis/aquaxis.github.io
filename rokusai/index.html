rokusai

GitHub: https://github.com/aquaxis/rokusai

Overview

Rokusai ("six colors") converts JPEG/PNG images into BMP/PNG limited to the seven-color palette of digital photo frames (black, white, yellow, red, blue, green), with white-balance correction, color enhancement, and Floyd–Steinberg dithering.

Features

  • Multiple image formats: JPEG/PNG input, BMP/PNG output
  • Color enhancement: saturation, contrast, brightness, gamma, and hue adjustments
  • Floyd–Steinberg dithering for high-quality palette conversion
  • Aspect-ratio-preserving resize with centered placement on a white background

Installation

Build from source with the provided Makefile:



git clone https://github.com/aquaxis/rokusai.git

cd rokusai

make

Usage

Convert an image with the default automatic white balance:



./rokusai input.jpg output.bmp

Manual white-balance gains, color enhancement, and dithering options are documented in the repository README.
